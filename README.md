 blog-platform
-->Description

This is a simple Blog Platform developed using HTML, CSS, and JavaScript. Users can create blog posts and view them instantly on the webpage. The project demonstrates basic content management functionality and user interaction.

-->Features
-Create new blog posts
-Display blog posts dynamically
-Simple and user-friendly interface
-Responsive design
-No database required

-->Technologies Used
HTML
CSS
JavaScript

-->Usage
-Enter a title in the Post Title field.
-Enter content in the Write your blog field.
-Click the Create Post button.
-The blog post will be displayed below.
